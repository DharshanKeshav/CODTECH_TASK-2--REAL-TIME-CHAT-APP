# Snap Crumb ⚡

**Snap Crumb** is a real-time messaging platform designed for fast-paced conversations with a unique "Cracked Biscuit" aesthetic. It combines high-performance messaging with a playful, high-contrast dark theme.

## ✨ Key Features
 **Real-time Messaging:** Instant message delivery and receipt via Supabase.
 **Unique UI:** Custom "Cracked" bubble styles and "Crumbs" feed.
 **Lightning Effects:** High-voltage accent colors and glow effects for an electric user experience.
 **Secure Auth:** Seamless user authentication and profile management.
 **Responsive Design:** Optimized for both desktop and mobile "snapping."

## 🚀 Tech Stack
 **Frontend:** React + TypeScript + Vite
 
 **Styling:** Tailwind CSS + Framer Motion (animations)
 
 **Database/Backend:** Supabase (Realtime, Auth, Storage)
 
 **Components:** Shadcn UI + Lucide React (icons)

## 🛠️ Getting Started

### Prerequisites

 Node.js (v18 or higher)
 npm or pnpm

### Installation
   
   1. Clone the repository:
   
      https://github.com/DharshanKeshav/CODTECH_TASK-2--REAL-TIME-CHAT-APP.git
      
   3. Navigate to the project folder:
      
      cd snap-crumb
      
   3.Install dependencies:
   
      npm install
      
   4.Configuration
   
      Create a .env file in the root directory and add your Supabase credentials:
      VITE_SUPABASE_URL=your_supabase_project_url
      VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

   5.Running Locally
     
     npm run dev
